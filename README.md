# Wordimo

A customizable word guessing game. Pick a word length, then guess the secret word in 5 tries or fewer. After each round, you see the word's definition.

Built with **React**, with random words from [Random Word API](https://random-word-api.herokuapp.com) and definitions from [Free Dictionary API](https://freedictionaryapi.com).

Play it at [megbort.github.io/wordimo](https://megbort.github.io/wordimo/).

— Megan Krenbrink

---

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build

# Run tests
npm test
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

### Deployment

Pushes to `master` build and deploy to GitHub Pages via `.github/workflows/deploy.yml`.
